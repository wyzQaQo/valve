## 技术要点
- next-intl v4 + Next.js 16 App Router: `[locale]` 段 + `generateStaticParams` 自动生成多语言页面
- `proxy.ts`（非 middleware.ts）是 Next.js 16 的中间件新名称
- `createNextIntlPlugin` 路径为 `./src/i18n/request.ts`
- 数据层 (valves.ts) 保持现有结构，i18n 仅覆盖 UI 文本
- Phosphor Icons 的 CaretDown 名（非 ChevronDown），从 `@phosphor-icons/react/dist/ssr` 导入
- `NonNullable<typeof v>` 类型收窄替代 `.filter(Boolean)`
